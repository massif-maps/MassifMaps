Follow this guide to write proper documentation every time [write-documentation.md](./references/write-documentation.md)

Default is **no documentation**: comment only the WHY the code cannot carry, and pick the right home (code comment / `all/modules/*.i` doc comment / root `CLAUDE.md` / `docs/`) before writing a line.

A code comment is **3 lines hard max, 1 the norm**. A fourth line means it belongs in `docs/`.
