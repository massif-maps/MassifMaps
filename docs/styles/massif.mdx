# Massif

Massif is a family of five map styles on [OpenMapTiles](https://openmaptiles.org/schema/) vector
tiles, written once and published two ways: as **MapLibre / Mapbox GL** styles, and as a
**CartoCSS** project for the Massif Maps SDK, where the variant and a dozen other choices are live
style parameters.

| Variant | For |
|---|---|
| `streets` | the everyday map: Mapbox Standard's look, POIs by category, 3D buildings |
| `outdoor` | streets plus relief, contours, trails by SAC grade, MTB difficulty, waymarked routes |
| `topo` | outdoor on a cooler, map-like ground |
| `hybrid` | roads, labels and POIs over satellite imagery you supply (EOX's Sentinel-2 mosaic below) |
| `eink` | black on white, patterns instead of colour, for e-paper screens; inverts at night |

## Get it

| Flavour | What it is | Where |
|---|---|---|
| **MapLibre** | `<variant>.json` + sprite | `https://massif-maps.github.io/MassifMaps/styles/massif/<variant>.json` (latest), `…/massif/v<version>/<variant>.json` (pinned) |
| **CartoCSS** | the SDK project: `project.json`, one `<variant>.json` per variant, `.mss`, icons, `legend.json` | npm, GitHub release |
| **CartoCSS compiled** | the same compiled to mapnik XML, one `<variant>.xml` per variant | npm, GitHub release |
| **CartoCSS icon font** | the CartoCSS project with POI icons drawn from one bundled font (`MassifIcons.ttf`) instead of PNGs | npm, GitHub release |
| **CartoCSS icon font compiled** | that compiled | npm, GitHub release |

- **npm**: `npm install @massif-maps/styles` — one folder per flavour: `maplibre/`, `cartocss/`,
  `cartocss-compiled/`, `cartocss-iconfont/`, `cartocss-iconfont-compiled/`.
- **GitHub releases**: [`massif-styles-v*`](https://github.com/massif-maps/MassifMaps/releases), one
  zip per flavour (`massif-<flavour>-<version>.zip`) and the screenshots.
- **unpkg**, straight from npm: `https://unpkg.com/@massif-maps/styles@<version>/maplibre/<variant>.json`.

Which CartoCSS flavour:

- **Plain or compiled**: the same map. The plain project is parsed when the style loads, the
  compiled XML is not — pick compiled for startup time, plain to read or [extend](massif-extending.md)
  the style.
- **Sprite or icon font**: the same POIs. The icon-font flavour ships one 30 KB font instead of a
  folder of PNGs, and its source, so an app can draw its own icons
  ([your own POI icons](massif-sdk.md#fonts)); road shields, markers, the peak triangle and the town
  dots keep their sprite either way.

## Use it

- [With MapLibre or Mapbox GL](massif-maplibre.md) — the style URL, and adding the optional
  sources (bathymetry, contours, routes, satellite imagery).
- [With the Massif Maps SDK](massif-sdk.md) — loading a flavour, picking the variant, the style
  parameters, legends, merged archives.
- [Extending it](massif-extending.md) — a child project of your own; the OpenStreetMap-coloured
  example.
